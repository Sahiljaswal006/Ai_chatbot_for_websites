# Ai_chatbot_for_websites
An AI-powered website chatbot built using Python, NLP, and Retrieval-Augmented Generation (RAG) to provide intelligent, context-aware answers based on website content. It uses web scraping, semantic search, FAISS vector storage, and LLM integration to help users find information quickly through an interactive chat interface.

*Please add your own API key to use this project.

*Feel free to modify and customize the code to suit your website's requirements.
